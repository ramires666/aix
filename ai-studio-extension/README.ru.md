# Расширение AIX для Google AI Studio

Текущая версия расширения — 0.5.0. Оно соединяется напрямую с локальным агентом.

Установка готового комплекта, обновление и запуск описаны в [основной инструкции](../README.ru.md).
Для готового комплекта самостоятельная сборка не нужна. Текущий EXE агента alpha.9
скомпилирован и находится в `bin/aix` от корня проекта вместе с ZIP расширения.
При обновлении расширения обновите всю папку, включая `vendor`, нажмите Reload
в `chrome://extensions` и перезагрузите сохранённую вкладку AI Studio.
Если менялся агент, замените EXE при остановленном процессе и запустите его заново.
Gate обновлять и перезапускать не требуется.

В панели выбираются инструменты и разрешения. «Разрешить всё» включает все галочки,
«Снять все галочки» отключает их. «Запустить сеанс» подготавливает чат.
«Отключить» завершает сеанс расширения. Локальный процесс агента остаётся запущен.

# Расширение AIX для Google AI Studio

Текущая версия расширения — 0.5.8, агента — `1.5.0-ai-studio-alpha.10`.
Расширение соединяется напрямую с локальным агентом.

Установка готового комплекта, обновление и запуск описаны в [основной инструкции](../README.ru.md).
Для готового комплекта самостоятельная сборка не нужна. Готовый EXE агента alpha.10
входит в [Windows-комплект 0.5.8](https://github.com/ramires666/aix/releases/download/v0.5.8/AIX-0.5.8-windows-x64.zip).
При обновлении остановите прежний агент сочетанием Ctrl+C в его окне,
замените `webcodex-agent.exe` готовым EXE из архива и снова запустите `start-agent.bat`.
Замените всю папку `ai-studio-extension`, включая `vendor`,
нажмите Reload в `chrome://extensions`, обновите сохранённую вкладку AI Studio
и нажмите в панели **«Обновить инструкции»**, если сеанс уже запущен,
либо **«Запустить сеанс»**. Gate обновлять и перезапускать не нужно.
Агент alpha.10 скомпилирован в готовом комплекте; проверенный локальный EXE находится
в `bin/candidate-0.5.8/webcodex-agent.exe`. Запущенный старый EXE автоматически не заменяется.

**«Вставить ID чата»** добавляет маркер активного сеанса в поле сообщения AI Studio.
Набранный текст сохраняется; отправьте сообщение кнопкой Run самостоятельно.
Можно вставить маркер и в пустое поле, и повторно в уже начатом чате.
Маркер виден под заголовком «Сеанс» в панели и в консоли нового агента.
Если модель сообщает об отсутствии Helper, сначала запустите сеанс, проверьте
галочки `write_file` и `exec_command`, затем вставьте ID и отправьте запрос.
Кнопка не меняет выбранные разрешения.

Каждый вызов в консоли агента показывает имя инструмента, короткое описание и результат.
Обычный вызов занимает две строки, длительная команда — до трёх, включая её завершение.
Содержимое файлов и полный вывод команд остаются в результатах инструментов.
При перезагрузке исходного чата неотправленный результат сохраняется:
нажмите **«Передать результат»** после проверки чата. Команду повторять не нужно.
Новый пустой чат получает новый маркер и пустой список задач в панели;
старые операции сохраняются в журнале агента и не выполняются повторно.

В 0.5.7 поиск кнопки System instructions игнорирует декоративные иконки и учитывает
элементы с ролью кнопки. Если появляется `System instructions opener not unique (count=0)`
или новая подсказка «Не найдена кнопка System instructions», вручную откройте
**System instructions** в панели **Run settings**, оставьте редактор открытым
и снова нажмите **«Запустить сеанс»**. Уже открытый редактор расширение умеет использовать.
Если кнопки нет или ошибка повторяется, сохраните снимок всей страницы AI Studio:
одной панели расширения недостаточно, чтобы определить отличие интерфейса.

В панели выбираются инструменты и разрешения. «Разрешить всё» включает все галочки,
«Снять все галочки» отключает их. «Запустить сеанс» подготавливает чат.
«Отключить» завершает сеанс расширения. Локальный процесс агента остаётся запущен.
Большие Python- и Node-скрипты передаются интерпретатору через stdin с короткими
аргументами запуска, чтобы избежать ограничения длины командной строки Windows.
Документы создавайте через `write_file` с содержимым в сыром текстовом блоке.

Принятые вызовы инструментов от модели к Helper и подтверждённые результаты агента
автоматически сворачиваются штатной кнопкой AI Studio. Обычный диалог остаётся раскрытым.
Для просмотра служебного блока нажмите стрелку раскрытия.

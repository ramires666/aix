# Расширение AIX для Google AI Studio

Текущая версия расширения — 0.5.6. Оно соединяется напрямую с локальным агентом.

Установка готового комплекта, обновление и запуск описаны в [основной инструкции](../README.ru.md).
Для готового комплекта самостоятельная сборка не нужна. Текущий EXE агента alpha.9
скомпилирован и находится в `bin/aix` от корня проекта вместе с ZIP расширения.
При обновлении замените всю папку `ai-studio-extension`, включая `vendor`,
нажмите Reload в `chrome://extensions`, обновите сохранённую вкладку AI Studio
и нажмите в панели **«Обновить инструкции»**. Для версии 0.5.6 агент alpha.9
заменять и перезапускать не нужно. Gate обновлять и перезапускать не нужно.
EXE уже скомпилирован в готовом ZIP, самостоятельная сборка не требуется.

В панели выбираются инструменты и разрешения. «Разрешить всё» включает все галочки,
«Снять все галочки» отключает их. «Запустить сеанс» подготавливает чат.
«Отключить» завершает сеанс расширения. Локальный процесс агента остаётся запущен.
Большие Python- и Node-скрипты передаются интерпретатору через stdin с короткими
аргументами запуска, чтобы избежать ограничения длины командной строки Windows.
Документы создавайте через `write_file` с содержимым в сыром текстовом блоке.

[Сборка и проверки исходников](BUILD.ru.md).
[Протокол ответа модели](../docs/model-reply-protocol-v2.ru.md).

Принятые вызовы инструментов от модели к Helper и подтверждённые результаты агента
автоматически сворачиваются штатной кнопкой AI Studio. Обычный диалог остаётся раскрытым.
Для просмотра служебного блока нажмите стрелку раскрытия.

# Сборка и проверки AIX

Этот раздел предназначен для разработки. Установка готовых EXE и ZIP описана
в [основной инструкции](../README.ru.md). Проверенный EXE агента alpha.10 скомпилирован
в `bin/candidate-0.5.8` от корня проекта, самостоятельная сборка для установки не нужна.

Нужны Go 1.25 или новее, PowerShell и Node.js. Для проверок DOM нужен установленный Chrome.
Все команды выполняются из корня проекта.

`./build.ps1` собирает локальный агент и ZIP расширения в `bin/aix`.
`./build.ps1 -AgentOnly` собирает только агент. Параметр `-AgentOnly` пропускает упаковку расширения.
`build-agent.bat` запускает эту же компиляцию под Windows.
`start-agent.bat` запускает готовый агент из `bin/aix`.

```powershell
go test -tags aistudio ./cmd/agent ./internal/buildinfo ./internal/protocol
node --test ai-studio-extension/*.test.cjs
```

`go test` запускает Go-тесты. `-tags aistudio` выбирает локальную точку входа.
Три следующих пути выбирают агент, сведения о версии и протокол.
`node` запускает Node.js, `--test` включает встроенный тестовый режим,
`ai-studio-extension/*.test.cjs` выбирает тесты расширения. Проверки реальных EXE
и Chrome включаются полным сценарием выпуска.

```powershell
./ai-studio-extension/verify-release.ps1
```

Путь выбирает сценарий полной проверки. Он собирает локальный комплект в `bin/aix`,
проверяет Go, JavaScript, настоящий локальный EXE и DOM Chrome с временным профилем.
Сохранённая совместимость Gate проверяется отдельными временными бинарниками.
Параметр `-OutputDirectory` задаёт другую папку готового комплекта, например
`./ai-studio-extension/verify-release.ps1 -OutputDirectory 'W:\_python\aix\bin\candidate'`.
Замените пример пути на нужную полную папку. Рабочие агенты не перезапускаются.

При установке изменённого агента остановите прежний процесс, замените EXE и запустите
`start-agent.bat`. Для изменённого расширения обновите его папку, нажмите Reload
в `chrome://extensions` и перезагрузите сохранённую вкладку AI Studio.
Gate для локального комплекта обновлять и перезапускать не требуется.
Проверка в авторизованном чате AI Studio выполняется отдельно.

# AIX — как установить и начать пользоваться

AIX позволяет модели в Google AI Studio читать файлы и выполнять команды на вашем компьютере.
Вы пишете задачу в обычном чате. Расширение передаёт команды небольшой программе — агенту.

Эта инструкция подходит для Windows и Google Chrome.

## Быстрый старт из релиза

1. Скачайте [готовый ZIP для Windows](https://github.com/ramires666/aix/releases/latest/download/AIX-0.5.6-windows-x64.zip).
2. Распакуйте **весь архив** в постоянную папку, например `C:\AIX`.
3. Дважды нажмите `start-agent.bat`. Оставьте открывшееся окно работающим.
4. В Chrome откройте `chrome://extensions`, включите **«Режим разработчика»**, нажмите **«Загрузить распакованное расширение»** и выберите папку `ai-studio-extension` из распакованного архива.
5. Откройте [Google AI Studio](https://aistudio.google.com/), войдите в аккаунт и откройте чат. Откройте панель **WebCodex AI Studio Bridge**, нажмите **«Разрешить всё»**, затем **«Запустить сеанс»**. Если уже показано «Снять все галочки», сразу запускайте сеанс.

EXE в релизе уже скомпилирован. Сборка для установки готового ZIP не требуется.

## 1. Откройте папку AIX

На вашем компьютере проект уже находится в папке `W:\_python\aix`.
Откройте её в Проводнике.

Внутри найдите следующие файлы и папки.

| Что найти | Для чего это нужно |
| --- | --- |
| `start-agent.bat` | Запуск агента |
| `build-agent.bat` | Создание EXE агента из исходников |
| `ai-studio-extension` | Расширение для Chrome |
| `bin` → `aix` → `webcodex-agent.exe` | Готовая программа агента |

**На этом компьютере агент уже скомпилирован. Можно сразу переходить к шагу 2.**
Версия агента — `1.5.0-ai-studio-alpha.9`, расширения — `0.5.6`.
Готовый EXE в копии проекта находится в `W:\_python\aix\bin\aix\webcodex-agent.exe`.
Самостоятельная сборка для этой готовой копии не требуется.

Если вы скачали проект с GitHub через **Code → Download ZIP**, сначала распакуйте архив.
Такой архив содержит исходники. Для получения EXE выполните раздел
[«Если готового EXE нет»](#если-готового-exe-нет), затем вернитесь к шагу 2.

## 2. Запустите агент

1. В папке AIX дважды нажмите на `start-agent.bat`.
2. Дождитесь строки `Studio local ready` в открывшемся окне.
3. Оставьте это окно открытым. Его можно свернуть.

Агент готов к работе. Во время работы с AI Studio это окно должно оставаться запущенным.

Запускайте один экземпляр агента. Если окно уже открыто, используйте его.

Если появилось сообщение `Agent EXE is missing`, выполните раздел
[«Если готового EXE нет»](#если-готового-exe-нет).

## 3. Установите расширение в Chrome

1. Откройте Google Chrome.
2. Нажмите на адресную строку наверху.
3. Вставьте `chrome://extensions` и нажмите Enter.
4. Справа вверху включите **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»**.
6. Выберите папку `W:\_python\aix\ai-studio-extension`.
7. Нажмите **«Выбор папки»**.

Выбирайте саму папку `ai-studio-extension`. Внутри неё лежит файл `manifest.json`.
Если вы распаковали AIX в другое место, найдите `ai-studio-extension` в своей папке проекта.

В списке расширений появится **WebCodex AI Studio Bridge**. Под этим именем AIX сейчас отображается в Chrome.

### Если расширение уже было установлено из WebCodex

1. На странице `chrome://extensions` найдите прежний **WebCodex AI Studio Bridge**.
2. Выключите его переключателем на карточке.
3. Установите расширение из папки AIX по шагам выше.

Оставьте включённым один экземпляр расширения для AI Studio.

## 4. Закрепите кнопку расширения

1. В Chrome справа от адресной строки нажмите значок пазла **«Расширения»**.
2. Найдите **WebCodex AI Studio Bridge**.
3. Нажмите значок булавки рядом с его названием.

Кнопка расширения появится справа от адресной строки.

## 5. Откройте AI Studio

1. Перейдите на [Google AI Studio](https://aistudio.google.com/).
2. Войдите в свой аккаунт Google.
3. Откройте чат с доступной моделью.
4. Если эта вкладка была открыта до установки расширения, сохраните нужный чат и обновите страницу.
5. Нажмите закреплённую кнопку **WebCodex AI Studio Bridge**.

Справа откроется панель расширения. Под названием будут показаны версии скрипта и агента.
В разделе **«Локальный агент»** должен появиться ваш агент.

## 6. Разрешите инструменты и запустите сеанс

1. Выберите своего агента круглым переключателем рядом с его именем.
2. Нажмите **«Разрешить всё»**. Все галочки включатся.
3. Если кнопка уже называется **«Снять все галочки»**, оставьте её как есть — всё уже включено.
4. Нажмите **«Запустить сеанс»** вверху панели.
5. Дождитесь завершения подготовки чата.

Кнопка станет светло-зелёной. На ней появятся надписи **«Агент 1.5.0 подключен»** и **«Отключить»**.

«Разрешить всё» включает чтение и изменение файлов, запуск команд и автоматическую передачу
результатов в Google AI Studio. Прочитанные файлы могут передаваться вложениями.
Команды оболочки выполняются с правами вашей учётной записи Windows.

## 7. Проверьте работу

Напишите в чате AI Studio следующее сообщение и отправьте его обычной кнопкой Run.

> Покажи список папок, с которыми тебе разрешено работать. Используй list_allowed_roots.

Дождитесь ответа. Модель должна получить список папок от локального агента.
После этого можно давать задачи по работе с файлами и командами.

При включённой галочке **«Автоматически передавать результаты инструментов»**
расширение само возвращает результаты в чат.
Автоматически сворачиваются только принятые вызовы инструментов от модели к Helper
и подтверждённые результаты агента, отправленные модели. Обычный диалог остаётся раскрытым.
Служебный блок можно открыть стрелкой. Повторно открытый вами блок остаётся раскрытым.
После обновления страницы сворачивается и загруженная старая история Helper.
Кнопка **«Свернуть чат хелпера»** рядом со **«Снять все галочки»** сворачивает её вручную, включая повторно раскрытые служебные блоки.
Кнопка работает при остановленном сеансе и отключённом агенте.
Справа от «Сеанс» находится ползунок ширины чата и поля ввода. Положение `default` возвращает штатную ширину, `Max` использует всю доступную область. Шкала имеет шаг 10%. Настройка сохраняется и применяется к вкладкам AI Studio.

### Большие скрипты и документы

Для многострочного скрипта передавайте код через stdin, стандартный ввод процесса.
Команда `python -` запускает Python. Аргумент `-` задаёт чтение программы из
стандартного ввода. Команда `node -` делает то же для Node.js. Код помещается
в отдельное сырое тело после `---`. Это позволяет передавать большие скрипты
с кавычками и переносами строк, обходя ограничение длины командной строки Windows.
Параметры `python -c` и `node -e` передают код внутри командной строки и подходят
для коротких выражений. Для создания документа используйте `write_file`,
который принимает путь и содержимое отдельным сырым текстовым блоком.

Пока открыт редактор ответа модели, сеанс ожидает его закрытия. При скрытой
панели Run settings расширение открывает её перед вставкой системных инструкций.

## Как пользоваться в следующий раз

1. Запустите `start-agent.bat`, если агент сейчас закрыт.
2. Откройте AI Studio и нужный чат.
3. Откройте панель расширения.
4. Если показана кнопка **«Запустить сеанс»**, нажмите её.
5. Напишите задачу в чате.

## Как закончить работу

1. В панели нажмите **«Отключить»**, чтобы завершить сеанс этого чата.
2. Чтобы остановить сам агент, перейдите в его окно и нажмите Ctrl+C.

После отключения сеанса кнопка становится светло-красной.

## Как выбрать свою папку с файлами

Разрешённые пути задаются в `start-agent.bat` на том компьютере, где работает агент.
Если нужной папки нет в ответе `list_allowed_roots`, добавьте её следующим образом.

1. Остановите агент сочетанием Ctrl+C в его окне.
2. Нажмите правой кнопкой на `start-agent.bat` и выберите **«Изменить»**.
   В Windows 11 этот пункт может быть внутри **«Показать дополнительные параметры»**.
3. Найдите строку `"%agentPath%" --local` и оставьте её без изменений.
   Переменная `%agentPath%` содержит путь к найденному EXE.
   Параметр `--local` включает локальный режим запуска агента.
4. Прямо перед ней вставьте строку:

   ```bat
   set "WEBCODEX_ALLOWED_ROOTS=C:\MyProject;D:\Documents"
   ```

   `set` задаёт настройку для этого запуска. `WEBCODEX_ALLOWED_ROOTS` — список папок,
   доступных файловым инструментам агента. Замените `C:\MyProject` и `D:\Documents`
   на полные пути к своим существующим папкам. Их подпапки тоже будут доступны.
   Несколько путей разделяются точкой с запятой `;`. Если нужна одна папка,
   удалите `;D:\Documents`. Кавычки сохраните — они позволяют использовать пробелы в путях.
5. Сохраните файл и закройте редактор.
6. Снова запустите `start-agent.bat`.
7. В панели расширения нажмите **«Отключить»**, затем **«Запустить сеанс»**.
   Для проверки отправьте модели: **«Покажи разрешённые папки через list_allowed_roots»**.

Перезапустить нужно только агент и сеанс. Заменять агент, обновлять или перезапускать
Gate и расширение не нужно. Используется уже скомпилированный EXE из установленного
комплекта: рядом с `start-agent.bat` или в `bin\aix\webcodex-agent.exe` от корня проекта.
Готовый Windows-комплект можно скачать по ссылке в начале этой инструкции.
Самостоятельная сборка для изменения разрешённых путей не требуется.

Эта настройка ограничивает файловые инструменты агента. Команды оболочки сохраняют права вашей учётной записи.

## Если готового EXE нет

Этот раздел нужен для установки из исходников GitHub.

1. Распакуйте скачанный архив AIX в постоянную папку, например `C:\AIX`.
2. Установите **Go версии 1.25 или новее** с [официальной страницы Go](https://go.dev/dl/).
   Выберите установщик Windows с расширением `.msi` и завершите установку.
3. После установки Go откройте новое окно Проводника и снова перейдите в папку AIX.
4. Дважды нажмите на `build-agent.bat`.
5. Дождитесь сообщения `Ready local agent: bin/aix/webcodex-agent.exe`.
6. Закройте окно сборки нажатием любой клавиши.
7. Вернитесь к шагу 2 основной инструкции.

`build-agent.bat` компилирует агент для Windows. Полученный EXE находится в папке `bin`,
внутри неё — в папке `aix`. Расширение для установки уже лежит в `ai-studio-extension`.
Первая сборка может занять несколько минут и скачивает зависимости через интернет.

Если появилось сообщение о том, что `go` не найден, перезагрузите Windows после установки Go
и снова запустите `build-agent.bat`.

## Как обновить установленный AIX

### Обновилось расширение

1. Сохраните чат в AI Studio.
2. Обновите всю папку `ai-studio-extension`, включая папку `vendor`.
3. Откройте `chrome://extensions`.
4. На карточке **WebCodex AI Studio Bridge** нажмите кнопку обновления с круглой стрелкой.
5. Обновите сохранённую вкладку AI Studio.
6. В панели нажмите **«Обновить инструкции»**.
7. Запустите сеанс, если панель его запрашивает.

Для расширений 0.5.6 и 0.5.7 заменять агент alpha.9 и перезапускать его не нужно.
Gate обновлять и перезапускать не нужно. Готовый EXE агента alpha.9 включён
в Windows-комплект 0.5.6. Исправление расширения 0.5.7 доступно в исходниках;
агент для него заново не компилируется, самостоятельно собирать EXE не требуется.

### Обновился агент

1. Остановите прежний агент сочетанием Ctrl+C в его окне.
2. Поместите новый готовый EXE в `bin\aix\webcodex-agent.exe`.
   Если обновляетесь из исходников, вместо этого запустите `build-agent.bat`.
3. Запустите `start-agent.bat`.
4. В панели расширения снова запустите сеанс.

Для локального AIX обновление и перезапуск Gate не требуются.

## Если что-то не получилось

| Что произошло | Что сделать |
| --- | --- |
| Агент отсутствует в панели | Проверьте, что окно `start-agent.bat` открыто и в нём есть `Studio local ready`. Затем обновите вкладку AI Studio. |
| Кнопка запуска недоступна | Проверьте выбор агента и галочку разрешения передачи результатов в Google AI Studio. |
| Chrome сообщает, что отсутствует manifest | Выберите папку `ai-studio-extension`, внутри которой находится `manifest.json`. |
| В панели ошибка связи после обновления | Сохраните чат, обновите расширение на `chrome://extensions`, затем обновите вкладку AI Studio. |
| `System instructions opener not unique (count=0)` или «Не найдена кнопка System instructions» | В AI Studio откройте Run settings, вручную откройте System instructions и оставьте редактор открытым. Затем снова нажмите «Запустить сеанс». Исправление поиска кнопок и порядок обновления описаны в [инструкции расширения 0.5.7](ai-studio-extension/README.ru.md). |
| Агент сообщает, что путь запрещён | Укажите нужную папку по разделу «Как выбрать свою папку с файлами». |
| В панели красный текст ошибки | Скопируйте его целиком вместе с последними строками окна агента для разбора. |

## Какие файлы могут пригодиться позже

- `build.bat` собирает агент и ZIP расширения одним запуском.
- `build-agent.bat` собирает агент для Windows.
- `start-agent.bat` запускает готовый агент.
- `build-legacy.bat`, `build-legacy.sh` и папка `legacy` сохранены для будущей работы с Gate.

[Техническая инструкция сборки и тестирования](ai-studio-extension/BUILD.ru.md).

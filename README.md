# AIX для Google AI Studio

AIX соединяет чат Google AI Studio с файлами и командами на вашем компьютере.

## Быстрый старт из релиза

1. Скачайте [готовый ZIP для Windows](https://github.com/ramires666/aix/releases/latest/download/AIX-0.5.8-windows-x64.zip).
2. Распакуйте **весь архив** в постоянную папку, например `C:\AIX`.
3. Дважды нажмите `start-agent.bat`. Оставьте открывшееся окно работающим.
4. В Chrome откройте `chrome://extensions`, включите **«Режим разработчика»**, нажмите **«Загрузить распакованное расширение»** и выберите папку `ai-studio-extension` из распакованного архива.
5. Откройте [Google AI Studio](https://aistudio.google.com/), войдите в аккаунт и откройте чат. Откройте панель **WebCodex AI Studio Bridge**, нажмите **«Разрешить всё»**, затем **«Запустить сеанс»**. Если уже показано «Снять все галочки», сразу запускайте сеанс.

EXE в релизе уже скомпилирован. Сборка для установки готового ZIP не требуется.

В версии 0.5.8 можно вручную вставить ID чата. Маркер виден в панели и консоли агента,
а каждый вызов инструмента выводится с коротким описанием и результатом.
Исправлены доставка результата после перезагрузки и сброс задач при создании нового чата.
Для обновления замените и перезапустите агент, обновите расширение и вкладку AI Studio.
Gate обновлять и перезапускать не нужно. Готовый агент alpha.10 уже скомпилирован в ZIP.

## Установка на Windows

[Открыть простую пошаговую инструкцию](README.ru.md).

В инструкции показано, как запустить агент, установить расширение в Chrome,
подключить чат, выбрать папку с файлами и проверить работу.
Отдельно описана установка из исходников GitHub.

[Как задать разрешённые папки агента](README.ru.md#как-выбрать-свою-папку-с-файлами):
настройка одной или нескольких папок в `start-agent.bat`, перезапуск и проверка доступа.

На этом компьютере проект находится в `W:\_python\aix`.
Готовый агент уже скомпилирован в `bin/aix/webcodex-agent.exe`.
Запуск — двойным щелчком по `start-agent.bat`.

## Простое обновление

1. **Сохрани чат** в AI Studio.
2. **[Открой последний выпуск AIX](https://github.com/ramires666/aix/releases/latest)**, скачай архив для Windows с названием `AIX-...-windows-x64.zip` и распакуй его в отдельную папку. Вместо многоточия в названии будет версия выпуска. Агент в архиве уже собран, самостоятельно собирать ничего не нужно.
3. **Останови старый агент:** нажми Ctrl+C в его окне. Это завершит его работу.
4. **Замени агент:** в своей папке AIX замени старый `webcodex-agent.exe` новым из архива. Если старый EXE лежит в папке `bin` → `aix`, положи новый туда же. Свой `start-agent.bat` оставь — в нём могут быть твои настройки папок.
5. **Замени расширение:** скопируй из архива всю папку `ai-studio-extension` на место прежней, с заменой файлов. Вложенную папку `vendor` тоже скопируй.
6. **Запусти агент снова:** дважды нажми свой `start-agent.bat` — он запускает агент. Оставь его окно открытым.
7. **Обнови расширение в Chrome:** введи `chrome://extensions` в адресную строку, найди **WebCodex AI Studio Bridge** и нажми круглую стрелку на его карточке. Этот адрес открывает список расширений Chrome.
8. **Обнови вкладку AI Studio** и открой панель расширения. Если сеанс уже запущен, нажми **«Обновить инструкции»**. Если нет — **«Запустить сеанс»**.

Готово: вверху панели показаны версии скрипта и агента. Сравни их с версиями в описании скачанного выпуска.
**Gate обновлять и перезапускать не нужно.**
